## Per-task details

### AWS EC2 + VPC
- Terraform creates VPC, subnet, security group, EC2 instance
- SG opens only ports 22 (SSH from var.ssh_cidr) + 80 (HTTP)
- Instance type: t3.large (8 GB RAM) minimum for full stack

### Terraform
- terraform.tfvars.example: instance_type = "t3.large"
- outputs.tf: public_ip, domain, portfolio_url, ssh_command
- output.sh: helper script to source TF outputs before ansible
- variables.tf: domain_name variable, ssh_cidr validation

### Ansible
- site.yml: unified playbook for Phases 1-5
- inventory.ini: TODO block + terraform output helper
- group_vars/web/vault.yml: secrets documentation (vault or .env)
- site.yml prereqs: apache2-utils, python3-requests
- site.yml health fan-out: /health, /grafana/api/health, /kibana/api/status

### Docker
- compose.yaml: merged root compose with app, web, cloudflared,
  prometheus, node-exporter, grafana, elasticsearch, logstash, kibana, filebeat
- No separate monitoring/ or elk/ directories (merged into root)
- Named volume admin_sessions for session storage
- Docker network ajs (external)

### Cloudflare (HTTPS)
- cloudflared service in compose.yaml
- CLOUDFLARE_TUNNEL_TOKEN in .env or vault
- Named tunnel + real domain (not trycloudflare.com quick tunnels)
- OAuth redirect URI: https://ajs-suite.<domain>/admin/auth/callback

### Google OAuth
- Google Cloud Console: Web application client ID
- Authorized redirect URI: https://ajs-suite.<domain>/admin/auth/callback
- Authorized JS origin: https://ajs-suite.<domain>
- APP_BASE_URL=https://ajs-suite.<domain> in .env
- SECRET_KEY auto-generated by Ansible if placeholder detected
- ADMIN_EMAILS allowlist in .env

### Web resume login
- index.html serves public portfolio at /
- /admin/ redirects to Google OAuth login
- Allowlisted Google accounts land on admin panel
- Non-allowlisted accounts are denied (403)

### Prometheus
- Merge into root compose.yaml on network ajs
- monitoring/prometheus.yml with scrape configs
- /metrics endpoint in app.py (prometheus_client)
- Grafana datasource: http://prometheus:9090/prometheus/
- Node dashboard (node.json) showing CPU/RAM/disk
- NOT exposed publicly — curl <ip>:9090 → connection refused

### Grafana
- Merged into root compose.yaml
- Subpath: /grafana/ behind nginx
- GF_SERVER_ROOT_URL: https://ajs-suite.<domain>/grafana/
- GF_SERVER_SERVE_FROM_SUB_PATH: "true"
- GF_AUTH_ANONYMOUS_ENABLED: "false"
- Default admin password NOT shipped (GRAFANA_ADMIN_PASSWORD in .env)
- Provisioning: datasources + node dashboard JSON
- Access: https://<domain>/grafana/

### ELK (t3.large only)
- Merged into root compose.yaml
- elasticsearch: single node, 1 GB heap, memory_lock enabled
- logstash: beats input → elasticsearch output
- kibana: SERVER_BASEPATH: /kibana, basic auth via htpasswd
- filebeat: docker autodiscover → logstash:5044
- Kibana at https://<domain>/kibana/ with basic auth
- Discover → ajs-* index pattern → app container logs visible
- **SKIP on t3.micro or t3.medium without downgrading compose**
- ELK requires >= 4 GB RAM; t3.medium (4 GB) may OOM

### Jira
- .env.example: JIRA_BASE_URL, JIRA_EMAIL, JIRA_API_TOKEN,
  JIRA_PROJECT_KEY, JIRA_WEBHOOK_SECRET
- /webhooks/jira: inbound webhook (verify JIRA_WEBHOOK_SECRET)
- /admin/jira/create: admin-created issue via Jira REST API
- Webhook URL in Jira Settings: https://ajs-suite.<domain>/webhooks/jira?secret=<secret>
- Events: Issue created, Issue updated, Comment created
- Confirmed: these routes do NOT require HTTPS (Flask behind tunnel is fine)

### Minikube (separate environment)
- terraform/environments/minikube/: separate TF env, opt-in only
- Does NOT run on the main app host
- k8s/manifests/: real K8s YAML (replaces k8s/minikube/ README-only)
- Bootstrap: docker build → minikube image load
- Access: kubectl get pods -n ajs, curl http://<minikube-ip>:<nodeport>/
- Marked as separate because it cannot coexist with ELK on same host
